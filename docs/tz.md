Крок 1. Тема проєкту
•	Назва застосунку: PrintSpace
•	Призначення (одне речення): Повнофункціональний інтернет-магазин з продажу всіх видів принтерів, витратних матеріалів та керування замовленнями.
•	Цільова аудиторія: Роздрібні покупці, офісні клієнти, інженери та фахівці з 3D-друку.
•	Перевірка допуску:
o	дані зберігаються в реляційній базі даних;
o	є реєстрація та три ролі (гість, клієнт, адміністратор);
o	є понад дві пов'язані сутності (users, products, categories, orders, order_items);
o	повний цикл CRUD для даних товарів, замовлень та користувачів реалізовано.

Нефункційні вимоги:
•	Продуктивність: Швидке завантаження сторінок каталогу (до 1.5–2 с) завдяки оптимізованим запитам та індексації таблиці товарів.
•	Безпека: Безпечна автентифікація (JWT / сесії з хешуванням паролів через bcrypt), валідація вхідних даних на сервері для запобігання SQL-ін'єкціям та XSS.
•	Адаптивність: Повністю адаптивний дизайн (Mobile-First) для зручного перегляду каталогу та оформлення замовлень зі смартфонів і планшетів.

Крок 5. Сутності та зв'язки
Сутність	Основні атрибути	Первинний ключ
users	id, name, email, password_hash, role, created_at	id
categories	id, name, slug (напр., laser, inkjet, 3d-printers)	id
products	id, title, description, price, stock, category_id, image_url, created_at	id
orders	id, user_id, total_price, status, shipping_address, created_at	id
order_items	id, order_id, product_id, quantity, price	id
Зв'язки:
•	categories 1:N products (Одна категорія містить багато товарів-принтерів. Зовнішній ключ: category_id у таблиці products).
•	users 1:N orders (Один користувач може робити багато замовлень. Зовнішній ключ: user_id у таблиці orders).
•	orders 1:N order_items (Одне замовлення містить кілька позицій товарів. Зовнішній ключ: order_id у таблиці order_items).
•	products 1:N order_items (Товар може входити до багатьох замовлень через проміжну таблицю позицій. Зовнішній ключ: product_id у таблиці order_items).

Крок 6. Обґрунтування стеку
Рівень	Технологія	Чому доречна саме тут
Клієнт	React.js	Дозволяє реалізувати зручний інтерфейс інтернет-магазину: інтерактивний каталог з фільтрами, динамічний кошик та миттєве оновлення даних без перезавантаження сторінок.
Стилі	SCSS + БЕМ	Забезпечують зручну структуру стилів для великої кількості компонентів інтернет-магазину (картки товарів, кнопки, модальні вікна, форми).
Сервер	Node.js (Express) / PHP	Забезпечують швидку обробку запитів інтернет-магазину, керування сесіями користувачів та бізнес-логікою кошика/замовлень.
База даних	PostgreSQL / MySQL	Надійна реляційна база даних, яка ідеально підходить для управління складними зв'язками «Товари — Категорії — Замовлення — Користувачі».
Розміщення	Render / Хмарний хостинг	Зручна платформа для безперервного розгортання вебзастосунку та підключення бази даних.
